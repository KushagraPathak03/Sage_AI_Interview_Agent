# Sage - AI Interview Agent

Sage is an AI-powered adaptive voice interview platform that conducts technical interviews, analyzes candidate responses in real time, builds a knowledge graph of demonstrated skills, and generates recruiter-ready evaluation reports.

## Features

- Resume-aware interview generation
- Adaptive questioning based on experience
- Live voice interview using LiveKit
- Real-time answer evaluation
- Candidate Knowledge Graph
- Resume project validation
- Recruiter Dashboard
- AI-generated evaluation reports
- AWS Cloud deployment
